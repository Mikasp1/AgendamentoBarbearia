\# Sistema de Agendamento em Barbearia



Projeto desenvolvido para o trabalho prático de POO



\## Funcionalidades

\- Cadastrar agendamentos

\- Remover agendamentos por ID

\- Listar agendamentos

\- Ordenar horários utilizando (Bubble Sort)



\## Como executar

Abra o projeto em uma IDE Java, como IntelliJ IDEA, e execute o arquivo "Main".
